# ВкусДом — страница «Все бренды»

Вёрстка страницы «Бренды» для гипермаркета ВкусДом по макету из Figma.
Собирается Gulp'ом: Pug для разметки, SCSS для стилей, esbuild для скриптов.
Слайдер популярных брендов на Splide, остальное руками.

Почему Splide, а не Swiper: на странице один простой горизонтальный слайдер
без пагинации и эффектов, и тащить ради него Swiper (под 150 КБ минифицированного
js плюс css) не хотелось. Splide весит около 30 КБ, без зависимостей, стили
свои, стрелки внешние и вешаются на обычные кнопки через `splide.go('<')`.
Swiper к тому же от версии к версии заметно меняет api и css-переменные,
а тут хотелось, чтобы через год всё обновилось без переделки.

## Как запустить

Нужен Node 18+ (я сидел на 20, версия лежит в `.nvmrc`).

```bash
npm install
npm run dev      # локальный сервер на http://localhost:3000, перезагружается сам
npm run build    # чистая сборка в dist/
npm run zip      # собирает VKUSDOM-brands.zip — то, что уходит заказчику
npm run deploy   # заливает dist/ в ветку gh-pages
```

## Где что лежит

Всё, что правится, находится в `src/`. В `dist/` руками ничего не трогать,
он перезаписывается при каждой сборке.

```
src/
  tmp/                 Pug-шаблоны
    index.pug            сама страница
    layout/default.pug   каркас html: head, шапка, подвал, подключение css/js
    module/header        шапка — логотип, кнопка каталога с поиском, выбор способа
                         получения, иконки, строка категорий
    module/footer        подвал
    module/brands        три блока страницы: popular (слайдер), alphabet, list
    _config/helper.pug   миксины breadcrumbs, ico (иконка из спрайта), logo
    _config/brands-data  все данные страницы: буквы алфавита, списки брендов,
                         популярные бренды. Менять контент — сюда
  scss/
    config/              переменные, миксины, брейкпоинты
    main/style.scss      базовые вещи: шрифты, .container, .icon, заголовки
    layout/              header.scss, footer.scss
    module/              button, breadcrumb, brands
    module__base.scss    точка входа, тут список подключаемых модулей
    module__reset.scss   reset
    module__splide.scss  базовые стили Splide
  js/
    scripts.js           подключает модули
    modules/             header.js, slider.js, alphabet.js
  icons/                 svg-иконки, из них собирается спрайт img/icons/sprite.svg
  img/brands/            логотипы популярных брендов
  fonts/                 Geologica, ttf конвертируется в woff2 при сборке
```

## Что важно знать

- **Классы.** Везде префикс `vd__`, чтобы не конфликтовать со стилями сайта
  при встраивании. Схема БЭМ: `vd__блок--элемент`. Состояния через `is-active`,
  `is-disabled`. Хуки для js начинаются с `js--`, стили на них не вешаем.
- **Логотипы брендов** в слайдере взяты из макета, лежат в `src/img/brands/`
  как png 400px шириной, при сборке к ним добавляются webp и avif. Карточка
  215×150, картинка вписывается с запасом по высоте и обрезается краями карточки.
- **Размеры** в scss пишутся в px, при сборке pxtorem переводит их в rem
  с базой 16px. Так что если в макете 24px, пишем 24px.
- **Иконки** добавляются просто: кладёшь svg в `src/icons/`, в pug вызываешь
  `+ico('имя')`. Спрайт пересоберётся сам.

## Брейкпоинты

- до 768px — мобилка, алфавит переезжает в несколько рядов
- до 1023px — планшет
- от 1216px — десктоп, контейнер 1344px с полями 48px
